# BFEX

Brainfxxk, 通过我自己的预处理器新增了一些语法

## 示例

### 输入

```
[Hi.] /* 这是一个注释 ++--. */
/* 定义一个宏, 宏内容不能含有"}", 使用"@"代表传入的参数 */$square{>@[<@>-]<.}
/* 调用一个宏, 参数不能含有")" */$square(++++++)
```

### 输出

```
[Hi.]

>++++++[<++++++>-]<.
```

## 体验方法

### 在线

[在线](https://tools.liaoxyucm.top/bfonline), 请先将处理器设置为"宏和注释预处理器"
